Forecasts GTA VI's launch-day Twitch viewers hour by hour: a shape model fitted on past AAA launches' release-day curves (rolling-midnight console launches), anchored on the first hour's count, with honest lognormal uncertainty. Offline leave-one-out pinball loss ~0.27 vs ~0.39 for the house persistence baseline.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
